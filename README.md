## The problem
Students and first-time renters often sign agreements they cannot fully understand.
Hidden deposit deductions, lock-in periods and penalties are easy to miss, and legal help is costly.

## The solution
Upload or paste an agreement. Haunted Clauses:
- splits it into clauses and flags risky ones
- explains each clause in plain English, Hindi or Marathi
- shows the original clause next to every explanation
- gives a 0-100 "Scare Meter", questions to ask and safer wording to request

> Informational only. Not legal advice. Consult a qualified professional for important decisions.

## Key features
- Upload a PDF or photo, paste text, or try the built-in sample agreement
- Rental, Loan and Internship document types
- English / हिन्दी / मराठी explanations
- Clause-level risk cards (Low / Medium / High)
- Scare Meter, questions to ask, safer wording
- Reports auto-delete after 24 hours

## How it works
1. User uploads or pastes an agreement
2. Text is extracted and split into clauses
3. Each clause is checked by an AI model against a risk checklist
4. The model returns structured JSON (clause, risk level, category, explanation, questions, safer wording)
5. The report page shows the Scare Meter and clause cards

## Run locally
1. Install Node.js (LTS)
2. Clone this repo and open the folder
3. Run `npm install`
4. Copy `.env.example` to `.env` and add your keys
5. Run `npm run dev`
6. Open the link shown in the terminal (usually http://localhost:5173)

## Deployment (AWS)
1. Push this repo to GitHub
2. In AWS Amplify, choose Host web app, connect GitHub, select this repo
3. Add the environment variables in Amplify settings
4. Save and deploy. Amplify gives an HTTPS URL.
